# Artikel 9. Subsidiehoogte
1. Het subsidiepercentage voor een project bedraagt 50%.
2. Het bedrag aan subsidiabele kosten voor een project bedraagt minimaal € 10.000,--.
3. De subsidie voor een project bedraagt maximaal € 12.500,--.
4. Het bedrag van de subsidie wordt verlaagd indien de normen van de Europese Commissie daartoe nopen.
