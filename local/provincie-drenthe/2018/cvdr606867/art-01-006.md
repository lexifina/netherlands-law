# Artikel 1.6. Algemene toetsingscriteria
Om voor subsidie in aanmerking te komen, wordt voldaan aan de volgende criteria:
a. het project is bovenregionaal toepasbaar;
b. het project is additioneel aan gemeentelijk beleid;
c. voor het project is aantoonbaar draagvlak van de gemeente waar het project plaatsheeft;
d. het project is uniek binnen Drenthe en heeft een voorbeeldwerking voor de regio (overdraagbaar);
e. de resultaten van het project zijn aantoonbaar.
