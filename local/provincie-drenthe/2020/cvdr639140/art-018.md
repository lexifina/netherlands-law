# Artikel 18. Intrekken VIA 2019 softwareontwikkeling en overgangsrecht
De VIA 2019 softwareontwikkeling wordt ingetrokken op de dag dat de VIA 2020 software ontwikkeling in werking treedt. Op aanvragen die zijn ingediend op grond van de VIA 2019 softwareontwikkeling, blijft de VIA 2019 softwareontwikkeling van toepassing.
