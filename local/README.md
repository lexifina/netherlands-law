# Local regulations (CVDR)

Every regulation of the Dutch municipalities, provinces, water boards, joint arrangements and Caribbean public bodies that the Centrale Voorziening Decentrale Regelgeving (lokaleregelgeving.overheid.nl, KOOP) holds, with every consolidated version it keeps: one folder per authority, then per year the regulation first took effect, then per CVDR id; one file per article. Texts are copied from the CVDR XML as published (free of copyright and database right, as each CVDR record states) and checked word for word against it; images in the texts are not reproduced (their place is marked "[afbeelding]").
