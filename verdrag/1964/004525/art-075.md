# Article 75
1. After consulting the Consultative Assembly, if it considers it appropriate, the Committee of Ministers shall, by a two-thirds majority in accordance with Article 20, paragraph (d ) of the Statute of the Council of Europe, decide whether each member State which has ratified the Code and this Protocol has complied with the obligations of the Code and the Protocol that it has accepted.
2. If the Committee of Ministers considers that a member State which has ratified the Code and this Protocol is not complying with its obligations under these Acts, it shall invite the said member State to take such measures as the Committee of Ministers considers necessary to ensure such compliance.
