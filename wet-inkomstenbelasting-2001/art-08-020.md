# Artikel 8.20. Korting voor beleggingen in durfkapitaal
1. De korting voor beleggingen in durfkapitaal geldt voor belastingplichtigen van wie beleggingen in durfkapitaal zijn vrijgesteld ingevolge artikel 5.16.
2. De korting voor beleggingen in durfkapitaal bedraagt 1,3% van het gemiddelde van de bedragen die ingevolge artikel 5.16 op begindatum en op einddatum zijn vrijgesteld.
