# Artikel 1. Werkingssfeer en definities
1. Deze code bevat de gebiedsindeling van de netbeheerders, bedoeld in artikel 31, eerste lid, onderdeel d, van de Elektriciteitswet 1998.
2. Voor de toepassing van deze code gelden de begrippen en bijbehorende begripsbepalingen uit de Begrippencode elektriciteit.
