# Artikel 3.2. Aanvrager
1. Een subsidie kan worden aangevraagd door een instelling die een compositie of libretto wil laten vervaardigen.
2. Een aanvrager kan voor maximaal drie werken per jaar een aanvraag indienen.
3. Een aanvraag kan niet worden ingediend als de instelling op het moment van indienen reeds subsidie ontvangt voor het verstrekken van een reeks opdrachten als bedoeld in paragraaf 4.
