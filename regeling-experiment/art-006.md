# Artikel 6. Wijze van indiening
1. Het Stimuleringsfonds maakt via de website www.stimuleringsfonds.nlbekend binnen welke tijdvakken een subsidieaanvraag op grond van deze regeling kan worden ingediend.
2. Binnen deze tijdvakken kan doorlopend worden ingediend.
3. Subsidieaanvragen worden behandeld op volgorde van indienen, de datum van indienen van een volledige aanvraag is daarbij leidend.
4. De aanvraag voor subsidie wordt via dedigitale aanvraagomgevingvan het Stimuleringsfonds Creatieve Industrie ingediend.
5. Aanvragen worden in de Nederlandse of Engelse taal opgesteld.
