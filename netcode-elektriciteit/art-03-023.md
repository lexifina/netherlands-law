# Artikel 3.23
1. Elektriciteitsproductie-eenheden van het type C voldoen aan de in deze paragraaf gestelde voorwaarden.
2. Elektriciteitsproductie-eenheden van het type C voldoen tevens aan de in paragraaf 3.4 gestelde voorwaarden, met uitzondering van artikel 3.13, zesde lid, en artikel 3.14.
3. Elektriciteitsproductie-eenheden van het type C voldoen tevens aan de in paragraaf 3.5 gestelde voorwaarden, met uitzondering van artikel 3.17, eerste lid.
