# Artikel 18. Wijze van indiening
1. Een subsidieaanvraag wordt elektronisch ingediend via de website www.rvo.nl/subsidies-regelingen/subsidieregeling-praktijkleren.
2. Een subsidieaanvraag voor een gerealiseerde praktijkleerplaats op Bonaire, Sint Eustatius of Saba wordt in persoon ingediend, op een hiervoor bestemde locatie die wordt bekend gemaakt op de website https://www.rvo.nl/praktijkleren/cn.
