# Artikel 3
1. Een aanvraag door een JAA persoon voor een type-certificaat voor een luchtvaartuig waarop JAR 25 of JAR 29 van toepassing is, is conform JAR 21.17 c vijf jaar geldig.
2. Een aanvraag door een JAA-persoon voor een type-certificaat voor een luchtvaartuig waarop andere dan in het eerste lid genoemde JAR's van toepassing zijn, is conform JAR 21.17c drie jaar geldig.
3. De minister kan de periode van geldigheid van een aanvraag op verzoek van de aanvrager zijnde een JAA-persoon overeenkomstig JAR 21.17 c verlengen.
