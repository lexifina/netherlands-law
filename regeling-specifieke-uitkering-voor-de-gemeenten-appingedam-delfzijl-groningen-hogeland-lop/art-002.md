# Artikel 2. Specifieke uitkering
1. De minister versterkt een eenmalige specifieke uitkering aan de gemeenten voor de uitvoering van projecten die zijn goedgekeurd door de bestuursvergadering van het nationaal programma Groningen.
2. De specifieke uitkering bedraagt voor de gemeente:
a. Appingedam 15 miljoen, voor de uitvoering van het project Stadsvisie Appingedam;
b. Delfzijl 10,5 miljoen, voor de uitvoering van het project Gebiedsontwikkeling Centrum Zuidoost;
c. Groningen 17.1 miljoen, waarvan:
1° 3,8 miljoen voor de uitvoering van het project Dorpsvernieuwing Ten Post, dorpshart;
2° 4,95 miljoen voor de uitvoering van het project Dorpsvernieuwing Ten Post, Nije Buurt;
3° 1,5 miljoen voor de uitvoering van het project Dorpsvernieuwing Ten Post, pilot verduurzaming;
4° 2,25 miljoen voor de uitvoering van het project Dorpsvernieuwing Ten Boer, Hart Ten Boer;
5° 2,6 miljoen voor de uitvoering van het project Dorpsvernieuwing Woltersum;
6° 2,0 miljoen voor de uitvoering van het project Klimaatbiënnale;
d. Hogeland 14,6 miljoen, waarvan:
1° 11,6 miljoen voor de uitvoering van het project Centrumplannen Hogeland;
2° 3 miljoen voor de uitvoering van het project Kunstcentrum 'De Ploeg';
e. Loppersum 7,584 miljoen, waarvan:
1° 0,127 miljoen voor de uitvoering van het project Procesgeld Dorpenronde gemeente Loppersum;
2° 0,63 miljoen voor de uitvoering van het project Programma Jeugd Onderwijs en Leefbaarheid;
3° 0,945 miljoen voor de uitvoering van het project Aanleg warmtenet Loppersum Noord;
4° 0,454 miljoen voor de uitvoering van het project Opwaarderen haventerrein Huizinge;

10° 0,825 miljoen voor de uitvoering van het project Centrumplan Loppersum;

1° 0,88 miljoen voor de uitvoering van het project Organisatorische inrichting lokaal programma MG;
2° 1,07 miljoen voor de uitvoering van het project Ondersteuning dorpsproces Overschild;
3° 0,12 miljoen voor de uitvoering van het project Beleving en Verhaal van Overschild.
